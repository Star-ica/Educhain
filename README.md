# EduChain
1. Deploy `contract/EduChain.sol` on BOT Chain. The deployer becomes admin.
2. Set `CONTRACT_ADDRESS` in `js/app.js`.
3. Serve the folder (e.g. VS Code Live Server) and open `index.html`.
Roles: Admin registers institutions; institutions issue/revoke certificates; students view and share verify links; anyone can verify by ID (no wallet).
Store only hashes/CIDs of certificate files. Not audited; test on a testnet first.
